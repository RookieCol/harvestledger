# HarvestLedger

## Descripción

HarvestLedger es una aplicación de microservicios construida con NestJS, diseñada para ofrecer soluciones en el sector agrícola. Utiliza una arquitectura modular para gestionar diferentes aspectos como autenticación, gestión de granjas, y trazabilidad.

## Requisitos

- Node.js (18.x)
- NestJS (10.x)
- Docker (para contenedores y docker-compose)

# Instalación y Configuración

## Para iniciar la aplicación:
```bash
docker compose up --build
```
## Documentacion
Ejecuta: 
```bash
pnpm i && pnpm doc
```
